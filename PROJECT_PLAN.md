# Fantasy GM Roadmap

## Vision

Build a web application for managing one or more Sleeper fantasy football leagues.

## Phase 1 - Core

- Connect to Sleeper public API

- Add multiple leagues

- League dashboard

- Team pages

- Roster viewer

- Player search

## Phase 2 - Analysis

- Team grades

- Power rankings

- Dynasty values

- Draft pick tracker

- Position strengths

- Championship window

## Phase 3 - Trade Center

- Trade finder

- Trade calculator

- Team needs

- Buy-low / Sell-high

- League-specific recommendations

## Phase 4 - Intelligence

- Waiver recommendations

- Weekly reports

- Injury impact

- Rookie rankings

- AI assistant

## Future Ideas

- Startup draft simulator

- Rookie draft simulator

- Salary cap support

- Best ball support

- Redraft support

- Multi-league exposure tracker
